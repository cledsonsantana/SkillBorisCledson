# Exemplo exclusivamente técnico

Os arquivos deste diretório são sintéticos. Não descrevem um artigo, participantes ou resultados reais; não são evidência e não demonstram a qualidade científica de uma análise.

O agente usa `record.json` e `source.txt` para executar os comandos de validação/renderização de INSTALL.md, sempre com saída num diretório temporário. Nenhum instrumento oficial é aplicado: o item DEMO somente exercita o contrato do registro.

Uma saída que passa neste teste ainda não demonstra análise de PDF, conformidade com um manual, interpretação correta de gráficos nem diagramação final. Não reaproveitar as afirmações como conteúdo científico de um relatório real.
